# そよかぜ整骨院・鍼灸院(制作サンプル)

LuFTech ポートフォリオ② 小規模サイト(3ページ+ネット予約)のサンプルです。
**架空の院を想定した制作サンプルです。** 院名・住所・駅名・電話番号・料金はすべて仮のものです。

HTML / CSS / バニラJS のみで作っています(ビルド不要・ライブラリなし)。

## ページ

| ページ | パス | 内容 |
| --- | --- | --- |
| トップ | `/` | ファーストビュー・受付時間・こんなお悩みに・特長・はじめての方へ・施術案内(抜粋)・アクセス |
| 施術案内 | `/menu/` | 保険施術(使える/使えないを分けて説明)・鍼灸・自費メニューと料金・よくある質問 |
| ご予約 | `/reserve/` | 予約の手順・予約サービスの画面(見本)・電話予約・変更/キャンセル・ご来院の前に |

## ファイル構成

```
index.html
menu/index.html
reserve/index.html
assets/
  css/style.css    デザイントークン(色・文字・動き)と全ページのスタイル
  js/main.js       受付時間表の「本日」表示、出現アニメーション、FAQの開閉、祝日判定
  js/reserve.js    予約画面の見本(メニュー → 日時 → お名前と電話番号 の3段階)
  img/             写真・favicon
```

## 確認方法

ディレクトリ形式のリンク(`menu/` など)を使っているため、ローカルサーバーで開いてください。

```bash
python3 -m http.server 8000
```

→ http://localhost:8000/

## 実装メモ

- **高齢の方向け**:本文18px・注記16px以上、ボタン高さ56px以上、BIZ UDPゴシック。影は使わず線と背景色で区切る
- **電話・予約はどこからでも**:ヘッダーに電話番号とネット予約、スマホは画面下に「電話する」「ネットで予約」を常時表示
- **受付時間表**:休診は「休」+グレー背景の両方で表示。今日の曜日(祝日は「日・祝」)を陽だまり色で強調。スマホでは曜日を縦に並べ、横スクロールなし
- **動き**:出現600ms・8px・80msずつ(4個目以降は同時)・一度だけ。予約/電話ボタンと受付時間表は動かさない。`prefers-reduced-motion` ではすべて停止。JSが無効でも全コンテンツが表示される
- **予約画面は見本**:空き枠は日付から決まる仮データで、入力内容は送信・保存しない。日曜・祝日・木曜午後・土曜14時以降は自動で受付外になる。実案件では予約サービス(RESERVA・Airリザーブなど)の埋め込みに置き換える
- **地図**:見本のイラスト。実案件では Googleマップの iframe と、所在地を指す「地図アプリで開く」URLに差し替える
- **計測**:電話リンクには `data-track` を付け、`gtag` があればタップをイベント送信する
- 架空の院のため `<meta name="robots" content="noindex">` を設定している
